# 쇼핑 리스트 앱

localStorage 기반의 간단한 쇼핑 리스트 웹 앱입니다.

## 기능

- 아이템 추가 (Enter 키 또는 추가 버튼)
- 체크박스로 완료 처리
- 개별 아이템 삭제
- 완료된 항목 일괄 삭제
- 새로고침 후에도 데이터 유지 (localStorage)

## 실행 방법

### 방법 1: HTML 파일 직접 열기
`shopping-list.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

### 방법 2: Node.js 서버로 실행
```bash
node server.js
```
브라우저에서 http://localhost:8787 접속
